Controls and menus for the plans page

Every control below is live and built from plain HTML and CSS, with a few lines of script where a pattern needs it. No library. The first set copies what index.html and room_3d.css use today, in their own look. The second set is what the page could use, tied to the fixes agreed in notes/UI_CRITIQUE.md where one applies. Nothing here touches the model: it's a demo of looks and behaviour only.
